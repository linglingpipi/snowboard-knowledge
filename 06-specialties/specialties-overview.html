补充科目概述

以下科目不深入展开（本库聚焦「单板滑雪教练」主线），仅做认知了解，供你判断哪条支线值得后续单独成库。每个条目给：一句话定位 + 与主线滑雪的关系 + 是否适合你。

1. 竞技滑雪（Racing / FIS 竞速）

  • 定位：以竞速为目标，追求最短时间通过旗门。
  • 与主线关系：利用极致的刃技术、姿态与速度管理，是刻滑技术的"工程化 + 速度化"极限。
  • 是否深度学习：若你爱速度、追求技术极致可深挖；普通单板教学用不上，但能反向提升教练对刃角理解。
  • 延伸：正式竞技由 FIS/国际组织规范，等级与单纯教学体系不同。

2. 越野滑雪 / 滑雪登山（XC / Ski Touring / Ski Mountaineering）

  • 越野：在专用雪道上长距离滑行，侧重耐力与效率，与单板 Altauch 不同（更接近轮滑/跑步），不属于单板教学主线。
  • 滑雪登山：穿登山雪板徒步上升 + 滑行下山，近年在国内兴起；核心是体能 + 雪况判断 + 安全。它不追求花哨姿势，重"怎么在自然地形安全穿行"。

3. 野雪 / 粉雪（Freeride / Powder）

  • 定位：脱离机压道，进自然地形、深雪。
  • 与主线关系：是刻滑/自由式的"自然延伸"，技术难点在粉雪姿态、浮力管理、线路选择、雪崩安全（评估/团队/装备）。
  • 是否电动机：如常去野雪区，值得学；且雪崩安全（avalanche safety）教育异常重要，是教练职责边界。

4. 什么时候把它们「加进教学」？

  • 不违背安全、不早于基础的前提下，可作为进阶选修。
  • 想开野雪/登山课，必须有独立资质，非滑雪认证能覆盖——务必单独受训。
