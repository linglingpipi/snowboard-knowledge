单板滑雪教练理论知识库

面向具备高校滑雪队基础、目标今冬成为单板教练的学习者，把「会滑」提升到「会教」。本知识库既承载技术原理与动作模型，也提供可直接用于备课与上课的教学工具。

库定位

  • 读者画像：已有滑雪队基础（科班会滑），目标是今冬取得单板教练认证并授课。
  • 双定位：理论提升（懂原理）＋ 教学备课（会用）。
  • 单一事实源：Markdown 是唯一人工维护的内容；HTML 网页端由构建脚本从 MD 生成；Obsidian 直接把本目录作为 Vault 打开。改一处、处处生效。

线上访问

  • GitHub Pages（长期公开）：<https://linglingpipi.github.io/snowboard-knowledge/>
  • 本地预览：node serve.js → <http://localhost:4173/>（需运行后才可访问）
  • 更新线上：改 MD → node build.js 生成最新 site/ → 在 site/ 目录 git add -A && git commit && git push 推 gh-pages 分支即可。

阅读路线建议

  1. 先地基：通读 术语词典 与 核心模型，建立统一口径。
  2. 再看体系：读 体系全景，尤其你的目标体系（韩式 / JSBA）详解篇。
  3. 再入专项：韩式刻滑、JSBA 等专项能力。
  4. 最后会教：初学者教学法 ＋ 工具箱。
  5. 收束：读底层原理章，统一各大体系框架。

如何扩展（低门槛维护）

新增任何内容只需遵守三条约定：

  1. 加术语/概念：一律在 00-foundation/glossary.md（术语）或 core-models.md（概念）登记，其余篇只能引用、不得重复定义。
  2. 加新模块：新建目录 NN-英文kebab-case/，并在 progression-map 进阶路径图与 README 导航中登记。
  3. 加体系/等级：在 01-systems 对应区域篇补充，并在 comparison.md 更新等级对照表。

front-matter 规范（每篇必填）：

---
title: 中文显示名
tags: [主题标签]
type: glossary | concept | module | tool | reading
status: draft | stable
---

术语与引用约定

  • 英文热词正交名缩写、日文原词在 glossary.md 统一登记。
  • 全库使用 Obsidian 双链 打通「术语-概念-模块-体系」。
  • 中文 title 用于显示，英文路径用于路由与 双链。

在 Obsidian 中使用（Vault 方式打开）

本知识库根目录（即本 README 所在目录）本身就是一个 Obsidian Vault。请用 Obsidian「打开文件夹作为仓库」直接选中本目录，即可获得：

  • 双链与图谱（Graph View）：术语、概念、模块 的语义关系自动构成知识图谱，可视化各体系/模块/概念的网络。
  • 标签（Tags）：front-matter 的 tags 自动沉淀标签，可全局检索。
  • 模板（Templates）：.obsidian/templates.json 已把模板文件夹指向 _templates/（内含 new-module、glossary-term、lesson-note 模板），新建内容可直接套用、保持一致性。
  • 看板（Dataview，可选）：若安装社区插件 Dataview，打开 _templates/dataview-progress.md 可得"教案进度/术语总览/待完成文档清单"看板。
  • 进阶路径图：00-foundation/progression-map.md 内含 Mermaid 图，Obsidian 原生支持 Mermaid 渲染。
提示：本仓库的双链路径同时被 HTML 构建脚本 build.js 解析成站内页面链接。保持"文件名唯一"（各目录文件名不要重名）即可让双链在 MD ↔ HTML ↔ Obsidian 三处都能正确跳转。

与 HTML 站 / 源文件的关系（单一事实源）

知识库根（= Obsidian Vault）  ←  你只在 .md 上改内容
   ├── *.md                    ← 内容源（唯一事实）
   └── site/                   ← node build.js 生成的静态交互站（勿手工改）
  • 只认 Markdown 是唯一真源：改 .md → 运行 node build.js → site/ 自动重建。
  • site/、.obsidian/、_templates/、_assets/ 均为派生/工具内容。
  • HTML 端支持：左侧目录树、全文搜索、明暗切换、Mermaid 渲染、双链跳转。
