共享概念层

本页定义全库反复引用的底层动作模型。这些模型不专属于某体系，而是各体系（韩式、JSBA、美/加/欧）共通的物理与体术基础。全库概念口径统一于本页，其他模块只能复用，不得另定义。

读法建议：模型要结合"自检动作"来理解（比如看刃线、看重心落点），不要当作纯名词背。每条主轴下都附有图文示意与常见纠错。

四条底层主轴（核心分析坐标）

单板滑行的控制最终可归结为四条相互耦合的主轴。它们是后续所有专项（刻滑、回转、公园、教学）的分析坐标：

  1. 重心控制（CoM Control）
  2. 压力管理（Pressure Management）
  3. 刃的使用（Edge Use）
  4. 旋转机制（Rotation Mechanism）

延伸两个辅助轴：姿态/时机（Posture & Timing） 与 肩/平衡（Alignment & Balance）。

一句话理解：重心决定"身体往哪片刃靠"，压力决定"刃是否被抓牢"，刃决定"画的是线还是面"，旋转决定"板头由谁带着走"。四条叠加在同一套身体动作上。

1. 重心控制

  • 定义：对整体重心位置、方向（内侧/外侧、低/高、前/后）主动而有目的的控制。
  • 子模型：
  • 重心投影（CoM Projection）：整体重心的垂直落点相对脚掌支撑面（base of support）的位置，决定负荷落在前脚还是后脚、偏哪条刃。这是"重心交给哪只脚"的物理基础。
  • 重心转移（Lateral）：踝→膝→髋→肩做整体一致地移向弯内侧，让板刃自然咬进雪。注意是整体平移，不是上半身单独侧倾。
  • 纵向变化（Fore／Aft）：沿板纵轴的前倾或后靠，控制板头／板尾的负荷分配，影响入弯与速度。
  • 垂直向变化（Up／Down）：屈膝降低重心（蓄压）、伸膝升高（释放），与"压力管理"强耦合。
  • 常见误解：
  • 误区一：重心越低越好 → 过度下蹲反而把关节锁死、妨碍换刃；目的在稳定 + 指向刃。
  • 误区二：靠上半身"压" → 重心转移应走踝-膝-髋-肩整条链，上身单独歪会失去直线。
  • 自检：正面或侧面回看，头-肩-髋-膝-踝是否成一条整体倾斜的直线（而不是"折角"）。
  • 教学 cue：「重心交给弯的那只脚」「把重心送向弯内」「全身一起往下弯里滑」。

2. 压力管理

  • 定义：在换刃、入弯、弯底、出弯各阶段，对施加给板面的垂直负载强度（加压/减压）的节奏与时机控制。
  • "压力循环"四段（像海浪起伏，不是一顿一停）：
  1. 入弯·轻（软刃）：压力最小，便于转向
  2. 弯顶·压（抓地）：屈膝下压、把刃咬进雪，产生转弯的横向力
  3. 出弯·扬（回弹）：伸膝让板回弹、压力下降
  4. 换刃·失重（毫秒窗口）：利好时机，板一瞬间"浮起"，完成换刃
  • 教学表达 cue：「弯顶给一脚（加压）」「出弯站起来（减压 / 弹起）」。
  • 考试链：加压早晚决定弯型——早压＝长弧稳、符合教学；越靠近弯底压＝短弧直、刻滑速度高（韩式/JSBA 快速刻滑的节奏差异来源）。

3. 刃的使用

  • 定义：控制板刃与雪面的接触深度、受刃角（刃角）、用刃时机，是"刻滑 vs 搓雪"（carving vs skidding）的分水岭。
  • 子模型：
  • 受刃角（Edge Angle）：刃平面与雪面夹角，越大型弧越深、弯越小。主要来自脚踝（压前刃→倒脚跟）→膝→髋的链条。
  • 刃换（Edge Change）：前刃/后刃之间无停顿过渡——顺序是"先减压→反刃→再加压"。
  • 刃痕（Edging / Tracking）：自己在雪上留下的是"细长的一根线（carving）"还是"一片铺开的面（skidding）"，是一眼可判的核心指标。
  • 自检：滑完一弯回头看一眼——遇到的是线还是面？把一个"面"收成"线"，就是刻滑进步的主线。
  • 教学 cue：「切开雪，不是拖过去」「压下刃肩、让它咬住」。

4. 旋转机制

  • 定义：让板头转向的身体旋转来源，回答"是你主动带着板转，还是板拖着你转"。
  • 子模型：
  • 下肢旋转：以膝为轴、用小腿/大腿带板前端转向，入门最常见。
  • 髋（骨盆）旋转：由髋带动整板，中速/大弧最顺。
  • 上体反扭（counter）：上身朝向与板保持相对角，用于高速时的稳定与保线。
  • 协同使用（mono vs counter）：同向转动（momo）适合长弧，反向/反扭适合小弯，取决于想做"C弯"还是"甩尾快弯"。
  • 教学 cue：「用脚踝开始转，不要扭腰」「上身稳住，让下体自由转」「想让板快速转，就先释放再转，而不是硬拧」。

动作链（Common Action Chain）

把四条主轴在时间上连成一条可教的统一序列，成为教学与自查的固定顺序：

ALIGN（对齐/重心） → ANGLE（立刃/倾压） → PRESS（加压/持久） → ROTATE（旋转/扭转） → RELEASE（释放/换刃）→（返 ALIGN）
flowchart LR
  A[ALIGN 对齐/重心] --> B[ANGLE 立刃] --> C[PRESS 加压] --> D[ROTATE 旋转]
  D --> E[RELEASE 释压/换刃] --> A

闭合：RELEASE 的"失重换刃"正好又是下一弯 ALIGN 的开始。所谓"流畅"，就是这一链的每一环节都连续、无停顿、无叠加，而非五步一顿。

本模型的体系分工：每个体系强调的焦点不同：

体系强调的一环
韩式刻滑PRESS（持久压刃）＋ ROTATE（带动板）
JSBAALIGN（对齐）＋ 基础姿态先行
奥地利 APSIROTATE ＋ Control（主动旋转 + 长弧稳定）
美/加整体连贯，最重时机
