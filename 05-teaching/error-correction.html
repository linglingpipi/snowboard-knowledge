常见错误 → 根因 → 纠正方法

错误诊断是教练的核心能力：看到"没做对"只是起点，能追到"为什么没做对"（根因）才能对症纠正。本节以"错误现象 — 根因 — 纠正路径"对照，覆盖新手高频问题。

纠错顺序：先找最优先级（安全/功能），一次纠正一个，不堆量。

1. 常见错误与纠正表（主表）

现象根因纠正路径
重心总后仰心理恐惧先建立安全感，口令「将重心转移至前脚」
转弯失控速度超过当前能力在教学坡度控制速度、管理刃压；口令「先减速再转弯」
一换刃就摔换刃时机差 / 切换过猛先以「沿直线滑行」熟练单刃，再训练换刃时机
老不肯回转不敢倾倒、重心不跟上视线引导，先以慢速大弯建立信任
身体僵、节奏乱紧张 / 动作僵硬用轻松的小弯口令放松肌群，寻找节奏感

2. 常见根因分类（三大类）

  1. A 类 · 平衡与姿态根因：重心、站姿不正确 → 回到姿态基础。
  2. B 类 · 时机与节奏根因：换刃、发力时机不准 → 用节拍与节奏练习调试。
  3. C 类 · 心理与恐惧根因：恐惧、紧张 → 先化解情绪，提供充分安全感。
判别技巧：同一错误可同时涉及三类（A 技术 / B 时机 / C 时机），教练先判别是"不会（技术）"、"时机不对"还是"不敢（心理）"，再对症下药。

3. 逐步纠正示范（一个典型案例）

现象：新手换刃时有明显"咯噔"停顿、单侧腿锁死。

  1. 观察：暂停动作，观察瞬时视线、身体姿态。
  2. 判别：多为「换刃时机过早」+「对倾倒动作有所保留」。
  3. 纠正：
  • Step1 在缓坡慢速练习换刃时机，口令：「先看下一弯，再换刃」。
  • Step2 加入"伸展下肢减压"训练，令自重引导自然换刃。
  • Step3 借助节拍 / 轻快小弯建立流畅节奏。
经验判断：此类"咯噔"通常源于换刃时机过早/过快，而非力量不足——所以重点不是"更用力"，而是"放慢一拍、先看下一弯再换"。切勿要求学员"加力"，先修正流程与时间轴。

4. 教练提醒

  • 一次只改一个点，改完再叠加练习。
  • 保护学员安全感，不要一上来就上难度。
  • 用 检表 复盘纠正成效。
