公园自由式：基本功

从"会滑"迈向"会飞/会玩道具"前，先打牢自由式通用运动基础。公园不只是跳台/道具，而是同一套平衡、旋转、压缩、落地机制在不同载体（地形、道具、跳台）上的应用。本文的底层坐标来自 核心模型里的「重心 / 压力 / 旋转 / 刃」四条主轴。

递进原则：地形基本功未稳，不上道具；道具中小 terrain 未稳，不上跳台。 顺序永远排在"炫技"之前。

1. 自由式的三个底座（alphabet）

底座说明对应底层主轴教学 cue
平衡（balance）无论板下是什么，都能以中性姿态找到平衡点重心控制「站中间，随时能收能放」
踝/膝驱动（ankle/knee flex）用脚踝和膝盖吸收、缓冲、微调，而非用腰压力管理「不是腰来，是脚踝来接」
视线先行（eyes lead）眼睛始终看向目标落点/出点，身体跟随旋转机制「眼睛先到，板再跟」

补充：中性位（neutral position）

自由式的"基准站姿"与刻滑不同：刻滑追求深蹲压刃，自由式则追求中性、弹性、可双向应对——重心居中，前后可调，板既可"一度角"玩耍也可快速进入刻滑。这是「自由式 vs 刻滑姿态差异」的关键。

2. 基本功序列（不依赖跳台/道具也能练）

  1. 平衡板/地形滑：在平缓雪面、小坡、包地上练习保持中性位 + 微调。
  2. 旋转（spin）基本功：站定绕垂直轴的旋转启动，脚蹬 + 上身反拧（counter-rotation），练"旋转怎么来、怎么收"。
  3. 小跳（ollie/nollie）：不需要跳台——用板尾/板头的弹性和脚下的蹦板做的小跳，是跳台之前的必经弹跳。
  4. 平地旋转（flat spin）：带着小幅旋转的小跳，练旋转控制。
  5. Box/小道具：低矮宽道具上踩滑、旋转出——见 box/rail 路径。
  6. 小跳台（kicker）：真正的飞行入门，见 跳台路径。

3. 弹跳动作模型（pop）

蹦板（Ollie / Nollie）是自由式最重要的基础动作之一。

  • Ollie（后脚弹）：先把重心移到后脚，后脚踝用力向下弹/跳，板尾受力回弹，让板头抬起 → 在空中自然"升高后跟"。适合从平地借助地形做小跳。
  • Nollie（前脚弹）：反过来的前脚弹，多用于进阶。
  • 教学 cue：「先压后放」「脚底发力，别用大腿硬蹬」「落地屈膝缓冲接住」。

正确的跳之前先练"收"

初学者最常的问题是：跳起来后身体散掉/落地砸下去。先练收腿 + 屈膝缓冲（在平地和小地形上），建立落地稳定后再起飞。

4. 常见错误 → 根因 → 纠正

错误现象根因纠正方向
落地震得厉害没屈膝消化落地力先练「落地三连：缓冲→屈→站住」，再上高度
空中身体散上身失控、没收紧核心「收腹、夹臂」意识 + 落地前屈膝
只会直冲不会转向转体时机靠腰先练「转向用脚」为旋转控制打底
想直接上不出跳过基本功直跳回退到平衡/小跳/地形滑

5. 与整体进阶的关系

  • 基本功是所有公园品种的底线（跳、小道具、兔跳都共用）。
  • 学自由式的关键提醒：安全永远第一、循序渐进。详见 公园安全。
