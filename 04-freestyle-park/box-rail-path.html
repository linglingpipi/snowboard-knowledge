Box / Rail 路径：入门到进阶

Box 与 Rail 是自由式"道具"（Features）两大当家。它们考验的是平衡、压板、进出（approach/dismount），不考验飞行高度——因此在进阶路线里是跳台以前的重要练习场。

关键前提：先会在地面上稳住、会转向、会直排减速，上道具才安全。不具备的不上。

1. 道具动作模型

判断道具(长度/高度/朝向) → 直进瞄准中线 → 压上道具(接触) → 保持平衡滑过 → 离末端前准备出离 → 落地缓冲/直接接续
  • 接触前（approach）：像直滑一样直线瞄准道具中线，速度平坦。
  • 压上（load）：屈膝、重心微沉，让板面平稳"贴"上道具面/身。
  • 滑过（slide）：保持平衡、小幅微调，不来回大幅晃。
  • 接续（exit）：视线看远端，屈膝缓冲离开面，落地接续。

2. Box 与 Rail 的区别

Box（宽箱）

  • 表面较宽、较平，属最容易的入门道具。宽箱=稳。
  • 花样：直滑过 → 换刃（高压） → 90°（板与箱垂直） → 180°（跳转）…… 进阶边界。

Rail（窄滑轨）

  • 很窄（直径一根管/杆），几乎没有宽度容错，考验极致的平衡与压脚。
  • 先从 furition（板与轨垂直）练起，再换平行（同行），再转体/跳转进阶。
有序添加难度变量（按"一条新想法 = 一项新变量"）： 宽度小的（box 宽 → box 窄 → rail）→ 加旋转角度 → 加速度/高度。

3. 常见错误 → 根因 → 纠正

错误现象根因纠正方向
进道具就歪进前重心偏/瞄不准进前先练"直排瞄准"，重心居中
上了压不平过屈下压、重心前后漂「轻压迫、重心居中」用足踝微调
快到末端起步没看远、提前失衡视线看远端，出台前不屈膝
跳转中失去平衡起跳太敢、没控制轴线先无跳"踩上/踩下"，再低速小跳转

4. 比：把裁判变成"设计练习"

道具课的价值是：刻意把" 平衡+微调 "从雪面搬到窄窄、悬浮的确认。教练要把每一个道具变成"一组可重复的练习线路"（如：box 直滑→还原、rail 同行→旋转小 jump），让学员在低风险、可控里反复肝平衡。

教学 cue

  • 「直线、中线、微调」「别看脚下，看出端」「上板轻、过板稳、出板长」。
