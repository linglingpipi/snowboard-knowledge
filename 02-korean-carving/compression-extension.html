韩式刻滑：团身与压缩伸展

团身（deep tuck / 圧縮）与压缩-伸展（flexion-extension）是韩式高速刻滑最重要的形态控制，也是区别「刻滑=低身」还是「刻滑=肘压」的关键。定义见 团身，底层见 重心/姿态。

1. 团身（Deep Tuck）

定义

在高速刻滑中，把重心大幅压低、向弯内侧倾斜，同时腿深屈、髋外旋、上身靠向弯内，形成把体重「埋进」刃里的紧凑姿态。有点像蹲着但重心在弯内。

为什么韩式强调团身

  • 降低重心 → 抗侧向离心（高速弯内的离心力越大，越低越稳）。
  • 让压力落在刃上 → 深屈提高小腿对前刃/后刃的施压效率。
  • 进深弯而不飞 → 通过团身抵消高速离心，从而可以保持更大的倾角与更小弯。

组成

  1. 膝盖向前/向下屈（维持站姿，不塌坐）。
  2. 髋向弯内方向旋转（counter），骨盆压向弯内。
  3. 上身（肩）保持相对朝滑行方向，轻微向前伏。
  4. 手臂起平衡（不开合） — 头看向弯内侧（新方向）。

不是的

  • 不是「坐死」在后刃上（后蹲失效会失压）。
  • 不是「弯身低头看板」。
  • 不牺牲对齐（膝盖仍沿板）。

2. 压缩 / 伸展动态（Flexion & Extension）

压缩伸展是在每个弯内，沿纵向（身体竖直缩-伸）的有序变化，用来管理压力与速度。

与弯曲节奏

flowchart LR
  A[入弯：先轻盈伸展] --> B[叠加压力：压缩（屈膝屈髋）] --> C[弯底：最深压缩] --> D[出弯：伸展释压] --> E[换刃]

韩式的「压缩-伸展」次序

  • 入弯先伸：提前做一点点伸展，为上加速与加深创造空间。让它「越是将要加深越要浅尝伸」。
  • 弯中压缩：到压力极值处深屈，扶持深倾角。
  • 出弯伸展：略展液、把身体拉回，为下一弯的入弯新阶段留空间（RELEASE）。

cue

  • 「入弯先站起来一点，再把自己折下去。」
  • 「到顶点——吸、压；出来了——呼、伸。」

3. 「团身＝压缩的深偏」

把上述串起来：团身是压缩在弯最顶点的极值形态。不是任何时候都用力团，而是在高速、深弯、时间窗内用到极深。

  • 慢速/入门：不追求深团，先学会「压缩-伸展」节奏。
  • 中高速：逐步把压缩加深至接近团身。
  • 高速：真正的团身体现「贴与压」——韩式最有辨识度的一段。

教学提示 / 常见错误

常见错误根因纠正
塌坐于后刃为平衡而屈髋后坐保持胫骨直立、重心前走
低头看雪怕翻板头看向新弯
挤压数秒不动以为团身=静态只是顶点点极深，出弯仍要伸
开幕就团没先建立伸/点心先伸再压
