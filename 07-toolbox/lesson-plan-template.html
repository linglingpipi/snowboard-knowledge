□ 教案：一节课（复制此段）

# 课时教案：〔主题〕

## 基本信息
- 学员水平：〔新手 / 换刃期 / 基础刻滑〕
- 场地/坡度：〔教学区 / 绿道 / 蓝道〕
- 课时：〔60min / 90min〕·教练：〔〕

## 1. 开场（5’）：建立安全与目标
- [ ] 装备检查（[[05-teaching/learning-sequence]] 的 M区。）
- [ ] 安全（领导色对、沟通手势）
- [ ] 明确本节的目标（让学员说一遍）

## 2. 主练习（40–60’）
- 准备热身〔站姿/重心/小滑〕
- 单一焦点练习〔一句话描述动作 = cue〕
- 常见错误预案〔见 [[error-correction.md]] 〕
- 练习×2–3 次，拆骤放大

## 3. 收尾（5–10min）
- 复盘：三种能（做了什么、学了什么、还能怎么）
- 明确下次预告
- 安全离场、自行练习安排

## 4. 自我评估（课后）
- 学员是否达成目标？成功率 t/n
- cue 是否有效？哪句需改
- 下节改进点

备课心中五问（before 写教案）

  1. 今天一个目标是什么
  2. 对应 cue 是什么（见 cue 卡）
  3. 最可能错的部分？预防练习
  4. 如何保证安全（M区/场地）
  5. 如何让学员自主行动而非被动

附带模板变体

  • 单技能课：只留"单一焦点"段。
  • 进阶小组课：加"分层支点"（不同水平用不同难度）。
